# 🎮 Game Market Analytics Dashboard (Apache Superset)

Учебный проект: интерактивный BI-дашборд в **Apache Superset** для анализа рынка видеоигр — динамики цен, установок, достижений и вовлечённости игроков.

---

## 🎯 Бизнес-цель

Отслеживание трендов на рынке игр: динамика цен, пользовательский интерес через установки и достижения, вовлечённость игроков.

## 👥 Целевая аудитория

- **Топ-менеджеры** — оценка рынка, ценовая политика
- **Аналитики и продакт-менеджеры** — анализ эффективности игр, выявление точек роста

---

## 🗂️ Модель данных

Единый датасет в Superset построен на основе шести связанных таблиц: `games`, `players`, `players_games`, `prices`, `achievements`, `history`.

![Data model](images/1787920118508_image.png)

| Таблица | Ключевые поля | Назначение |
|---|---|---|
| `games` | `game_id`, `title`, `platform`, `developers`, `publishers`, `genres`, `supported_languages`, `release_date` | Каталог игр |
| `players` | `player_id`, `nickname`, `country` | Игроки |
| `players_games` | `player_id`, `game_id` | Установки игр (факт связи игрок ↔ игра) |
| `prices` | `price_id`, `game_id`, `usd`, `eur`, `gbp`, `jpy`, `rub`, `date_acquired` | История цен по валютам |
| `achievements` | `achievement_id`, `game_id`, `title`, `description`, `rarity` | Справочник достижений |
| `history` | `player_id`, `achievement_id`, `date_acquired` | Факт получения достижений игроками |

---

## 📈 Метрики дашборда

| № | Показатель | Логика расчёта | Источник |
|---|---|---|---|
| 1 | Количество игр | `COUNT(DISTINCT game_id)` | `games` |
| 2 | Количество уникальных игроков | `COUNT(DISTINCT player_id)` | `players` |
| 3 | Количество компаний-издателей | `COUNT(DISTINCT publishers)` | `games` |
| 4 | Количество компаний-разработчиков | `COUNT(DISTINCT developers)` | `games` |
| 5 | Количество установок игр | `COUNT(DISTINCT install_id)`, где `install_id = CONCAT(game_id, player_id)` | `players_games` |
| 6 | Количество достижений | `COUNT(DISTINCT achievement_id)` | `achievements` |
| 7 | Доля редких достижений | `(COUNT(DISTINCT CASE WHEN rarity = 'Platinum' THEN achievement_id END)::decimal / COUNT(DISTINCT achievement_id)) * 100` | `achievements` |
| 8 | Средняя цена игры | `AVG(rub_clean)` | `prices` |
| 9 | Медианная цена игры | `PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY rub_clean)` | `prices` |

## 🖥️ Страницы дашборда

### 1. Анализ игр

Общая картина рынка: сколько игр вышло за период, сколько компаний за ними стоит и как распределены жанры и релизы во времени.

- Количество игр, вышедших за период
- Количество компаний-разработчиков
- Количество компаний-издателей
- Количество релизов по платформам
- Распределение игр по жанрам
- Календарь игровых релизов

![Games analysis](images/games-analysis.jpg)

### 2. Анализ игроков

Кто играет, во что и на каких платформах — от географии до динамики год к году.

- Количество уникальных игроков
- Общее количество установок за период
- Распределение игроков по странам
- Топ-10 популярных жанров по установкам
- Распределение игроков по платформам
- Количество установок по платформам
- Количество установок на игру по платформам
- Распределение количества игроков по играм и платформам
- Изменение количества игроков год к году (YoY) по платформам

![Players analysis](images/players-analysis.jpg)

### 3. Стоимость игр

Ценовая аналитика: средняя стоимость, разброс по жанрам и динамика цен во времени и по играм.

- Средняя стоимость игры, руб.
- Средняя и медианная стоимость игр по жанру
- Динамика изменения средней цены по платформам
- Изменение цен по играм, %

![Cost of games](images/cost-games.jpg)

### 4. Игровые достижения

Вовлечённость игроков через призму достижений: сколько их получено, какие жанры дают больше редких наград.

- Общее количество полученных достижений
- Количество достижений в каждой игре
- Средний % редких достижений по жанру
- Количество достижений по жанру и платформе

![Game achievements](images/game-achievements.jpg)

## ⏳ Фильтры

| Фильтр | Область действия |
|---|---|
| Период (диапазон дат) | Глобальный / условный |
| Гранулярность (агрегация по времени) | Условный |
| Платформа | Глобальный |
| Жанр | Глобальный |
| Компания-разработчик | Глобальный |
| Компания-издатель | Глобальный |
| Название игры | Глобальный |
| Поддерживаемые языки | Глобальный |
| Месяц для анализа YoY | Локальный (только для чарта YoY) |

**Дефолтные значения:**
- Период: `2024-06-01 — 2025-01-01`
- Гранулярность: по месяцам
- Месяц для YoY (Jinja): `2024-12-01`

**Кросс-фильтрация** настроена по платформам: часть чартов выступает источником кросс-фильтра, остальные — принимают фильтрацию.

## 🛠️ Технические детали реализации

- Единый датасет собран из шести таблиц (`games`, `players`, `players_games`, `prices`, `achievements`, `history`) с настройкой связей между ними.
- Часть SQL-метрик написана с использованием **Jinja**-шаблонов, включая:
  - предварительную (pre-)фильтрацию по дате и платформе на уровне датасета;
  - специальный чарт «Изменение количества игроков год к году (YoY)», построенный на вспомогательном датасете с последовательностью месяцев и фильтре на его основе.

## 🧰 Стек

- **Apache Superset** — визуализация и дашбординг
- **SQL** (включая Jinja-шаблонизацию) — расчёт метрик
- Реляционная СУБД с таблицами `games`, `players`, `players_games`, `prices`, `achievements`, `history`
